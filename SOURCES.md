# Reference sources used in the Bullit v0.1 data

These are reference links for static specifications embedded in the first build. User-specific setup history comes from the supplied Bullit note/PDF.

- Santa Cruz Bullit 4 MY26 product support / build / geometry / frame data:
  https://www.santacruzbicycles.com/en-de/pages/product-support/bullit-4-my-26
- FOX 2026 38 owner manual / GRIP X2 setup reference:
  https://tech.ridefox.com/bike/owners-manuals/3103/fork--2026-38mm

The app deliberately leaves an exact Santa Cruz suspension-damping baseline blank until a bike/tune-specific manufacturer value is verified.
